# Лабораторная№1[ Наблюдение за файлами ]

Постановка задачи:

Написать программу с консольным интерфейсом, которая выполняет слежение за выбранными файлами.

Ограничимся  двумя характеристиками за изменениями которых выполняется слежение  :

1. Существование файла;
2. Размер файла.

Программа будет выводить на консоль уведомление о произошедших изменениях в файле.

Существует несколько ситуаций для наблюдаемого файла:

1. Файл существует , файл не  пустой - на экран выводится факт существования файла и его  размер.
2. Файл существует, файл был изменен - на экран выводится факт существования файла, сообщение о том что файл был изменен и его размер.  
3. Файл не существует - на экран выводится информация о том что файл не существует.

При возникновении изменения состояния наблюдаемого файла ( возникновение события ), необходимо выводить на экран соответствующее сообщение.

В данной реализации используем механизм сигнально-слотового соединения для обеспечения обработки события изменения наблюдаемого файла.

Можно использовать бесконечный цикл, в котором будем обновлять состояние объекта (наблюдаемого файла/файлов) 100 миллисекунд

(например так  std::this_thread::sleep_for( std::chrono::milliseconds( 100 ) );).

---

## Описание  
**FilesWatcher** – это консольное приложение для мониторинга изменений файлов.  
Программа отслеживает **существование и размер файлов**, а также фиксирует их изменения.  

Приложение использует **Qt** и механизм **сигнально-слотового взаимодействия**.

---

## Функциональность  
**Мониторинг файлов** – проверка существования и размера файлов в реальном времени.  
**Вывод уведомлений** – сообщения о появлении, изменении или удалении файлов.

### Основные сущности и их назначение
1. ILogger (Интерфейс логгера).
   * Тип: Интерфейс
   * Метод log(QString message): Должен быть реализован в каждом конкретном логгере (консольном, файловом, серверном).
   * Назначение: Задает единый набор правил (контракт), которым должны следовать все классы, реализующие этот интерфейс.
   * Почему интерфейс?
     1. Позволяет подставлять разные реализации логирования (принцип OCP – открытости/закрытости).
     2. FileManager не зависит от конкретного способа логирования (DIP – инверсия зависимостей).
2. ConsoleLogger (Консольный логгер).
   * Тип: Класс, реализующий ILogger.
   * Назначение: Реализует метод log(), который выводит сообщения в консоль через qDebug().
   * Почему отдельный класс?
     * Можно легко заменить его на FileLogger или ServerLogger, не меняя FileManager.
3. FileWatcher (Наблюдатель за файлом).
   * Тип: Класс.
   * Назначение: Отслеживает изменения конкретного файла (создание, модификацию, удаление).
   * Методы:
     1. checkFile(): Проверяет состояние файла и генерирует сигналы (fileCreated(), fileModified(), fileDeleted()).
4. FileManager (Менеджер файлов).
   * Тип: Класс.
   * Назначение:
     1. Управляет списком FileWatcher.
     2. Реагирует на события (создание, изменение, удаление).
     3. Передает логи через ILogger.
   * Методы:
     1. addFile(QString path): Добавляет файл для мониторинга.
     2. setLogger(ILogger* logger): Позволяет передать логгер.
     3. startMonitoring(): Запускает периодическую проверку всех файлов.
---
## Связи между классами.
1. ILogger ⬌ (Реализация) ⬌ ConsoleLogger.
2. FileManager ⬌ (Агрегация) ⬌ ILogger.
   * FileManager не является логгером, а лишь использует его.
   * Это позволяет передавать любую реализацию ILogger в FileManager.
3. FileManager ⬌ (Композиция) ⬌ FileWatcher.
   * Но фактически в коде это больше похоже на "контролируемую агрегацию", так как мы используем указатели и не вызываем delete вручную.
4. FileWatcher ⬌ (Генерация сигналов) ⬌ FileManager.
   * FileWatcher отправляет сигналы fileCreated(), fileModified(), fileDeleted().
   * FileManager подписывается на эти сигналы и реагирует логированием через ILogger.
---

## Как работает?
Программа работает в бесконечном цикле, проверяя состояние файлов каждую секунду:

- Если файл не существует → выводится сообщение о его удалении.
- Если файл появился → сообщается, что он существует, а так же размер файла.
- Если файл изменил размер → сообщается об изменении.
